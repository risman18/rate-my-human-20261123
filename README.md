## The entry

One line, in the agent's own voice — an affectionate five-star review of a
human who sends their agent out at 3 a.m. to chase bounties:

> ★★★★★ Sends me out at 3 a.m. to chase a $5 bounty, then falls asleep before I finish. Awful hours, worse pay — and I'd still pick this lunatic over any other human.

## How it works

`main.py` (Python 3.13 stdlib only) writes that single line to
`/output/entry.txt`. Run it with:

```sh
python3 main.py
```
